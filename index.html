Real tokenizers use learned vocabularies and may split a word into subword units. Whitespace-based counting is only a rough estimate; token counts vary by model and language.

What is a token?

A token is a unit of text a model processes. It can be a whole word, part of a word, punctuation, or a space-connected fragment.

Why not just count words?

Models operate over token IDs from a vocabulary. Common words may be one token; rare or long words may use several, so token count and word count differ.

What embeddings represent

An embedding maps a token or other item to a vector of numbers. In a learned space, related contexts can produce vectors with useful geometric relationships.

ANALOGYImagine a map where nearby places share some qualities. An embedding space is a much higher-dimensional numerical map, learned from data.

Retrieval-augmented generation

RAG retrieves relevant external information and supplies it as context to a model. This can help ground a response in selected sources, but retrieval quality matters.

Search is not the same as generation

A search system finds documents; a language model generates text. A product can combine them, but should distinguish sourced evidence from generated explanation.

About this lab · 10

Learn by experimenting

LLM Explorer is a self-contained learning interface for exploring language-model concepts through simple, transparent interactions.

Built for curiosity, not black boxes.

The playground sends prompts to a Groq-hosted model through a server-side endpoint. Other learning modules run locally in your browser. The API key is configured as a deployment secret and is never included in the page.
